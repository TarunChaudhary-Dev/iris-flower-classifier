# 🌸 Iris Flower Classifier

My second ML project — a flower classifier
built using KNN algorithm and Scikit-learn!

## 📌 About
Predicts which type of Iris flower it is
based on 4 measurements using K-Nearest
Neighbors (KNN) classification algorithm.

## 🌺 Flower Types
- 🌸 Setosa
- 🌺 Versicolor  
- 🌹 Virginica

## 🧠 What I Learned
- Classification vs Regression difference
- KNN algorithm working
- Train/Test split concept
- accuracy_score evaluation
- Scikit-learn library basics

## 🛠️ Tech Stack
- Python
- NumPy
- Scikit-learn

## 📊 Dataset
- Source: Sklearn built-in Iris dataset
- Size: 150 flowers
- Features: Sepal length, Sepal width,
  Petal length, Petal width

## 🚀 How to Run
pip install scikit-learn numpy
python iris.py

## 📈 How to Use
Enter 4 values separated by comma:
5.1, 3.5, 1.4, 0.2
Output: 🌸 Setosa

## 🎯 Model Accuracy
KNN with n_neighbors=5
